## 下午第2轮（15:08~15:50）— 根除假通关

### 核心发现：Interop DLL参数顺序与文档完全不同！

| API | 参数位置 | 文档预期 | 实际(DLL反射) |
|-----|----------|----------|---------------|
| Merge | FeatureExtrusion2 | 参数3 | **参数18** |
| StartType | FeatureExtrusion2 | 参数12 | **参数21(T0)** |
| StartOffset | FeatureExtrusion2 | 参数13 | **参数22** |
| Flip | FeatureCut4 | 参数2 | 参数2 ✅ |

**旧代码的致命bug：Merge一直在参数3（false），导致扁柄从未真正合并，生成了孤立的悬浮实体！**

### Discoveries via reflection

| 反射发现 | 值/签名 |
|----------|---------|
| FeatureExtrusion2签名 | (bool Sd,bool Flip,bool Dir,int T1,int T2,double D1,double D2,bool[4],double[2],bool[4],**bool Merge**,bool[2],**int T0**,**double StartOffset**,bool) |
| FeatureCut4签名 | 27参数，Sd=false才能工作 |
| InsertRefPlane签名 | (int FirstConstraint, double Dist, int, double, int, double) — 旧版API |
| swRefPlaneReferenceConstraints\_e | Distance=8（**不是1！**） |
| swRefPlaneReferenceConstraints\_e | **带s后缀**，不是文档中的单数形式 |

### 3个硬核突破

1. **StartOffset不支持** → 用InsertRefPlane(8, 0.0125, 0,0,0,0)创建偏移基准面（距前视0.0125）
2. **上视基准面草图Y正方向=模型Z负方向** → 坐标全部取负值
3. **CreateArc在此DLL不工作** → 用Create3PointArc替代

### 验证升级：GetBodies2硬验证
```
旧验证: GetFeatureCount > before  ← 草图本身就+1，特征数增长≠实体成功
新验证: GetBodies2(swSolidBody) 实体计数 ← 真正的几何验证
```

### 最终Clevis_Joint.cs架构
