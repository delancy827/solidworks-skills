# SolidWorks Skills for WorkBuddy

SolidWorks automation and design skills for WorkBuddy Agent.

## 📦 Skills

| Skill | Version | Description |
|-------|---------|-------------|
| [solidworks-automation](solidworks-automation/) | v3.1.0 | 自动化建模 / Automated modeling via Python COM API |
| [sw-designer](sw-designer/) | v2.1.0 | 参数化设计 / Parametric design guidance & best practices |

## 🚀 Quick Start

1. Copy skill folders to `~/.workbuddy/skills/`
2. WorkBuddy will auto-load them on next startup
3. Ask: "用 solidworks-automation 帮我建一个零件" or "用 sw-designer 检查我的设计"

## 📝 Language

Both skills support **Chinese / English** bilingual output.
